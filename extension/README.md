# 3D Inspector 사용법

ENOVIA(3DEXPERIENCE) 위젯 화면의 요소를 선택하면, 그 요소를 만든 소스 모듈(`DS/...`)을 알려주는 크롬 개발자도구 확장입니다. 찾은 모듈을 읽기 쉽게 보여주고, 수정한 번들 파일을 만드는 기능도 들어 있습니다.

## 1. 설치

1. [3d-inspector.zip](https://github.com/LeeOuHyoun/3d-inspector/raw/main/release/3d-inspector.zip)을 받아 고정된 위치(예: `C:\tools\3d-inspector`)에 압축을 풉니다. Node.js나 npm은 필요 없습니다.
2. 크롬 주소창에 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더(`manifest.json`이 있는 폴더)를 선택합니다.
5. 3DEXPERIENCE 페이지를 **새로고침**합니다. 확장은 페이지가 로드되기 전에 들어가야 하므로, 설치 직후 이미 열려 있던 탭은 반드시 새로고침해야 합니다.

> 크롬은 폴더 위치를 직접 읽으므로 설치 후 폴더를 옮기거나 지우면 안 됩니다. 업데이트할 때는 새 zip을 같은 폴더에 덮어 풀고, `chrome://extensions`에서 이 확장의 새로고침 버튼을 누른 뒤 페이지도 새로고침합니다.

## 2. 화면 구성

F12로 개발자도구를 열면 두 군데에 기능이 있습니다.

| 위치 | 용도 |
| --- | --- |
| **Elements** 탭 → 오른쪽 사이드바 **3D Inspector** | 선택한 요소의 모듈 정보를 자동으로 표시 |
| 상단 탭 **3D Inspector** (안 보이면 `»` 메뉴 안에 있음) | 프레임 선택, 요소 선택, 진단, NLS 검색, 이벤트, 모듈 보기, 패치 |

### 패널의 프레임 선택

위젯은 iframe 안에서 실행되므로, 패널 맨 위 드롭다운에서 **대상 프레임**을 골라야 합니다.

- 각 항목은 `[번들 N] 주소` 형식이고, N이 큰 프레임이 위에 옵니다. 보통 맨 위 항목이 위젯 프레임입니다.
- 목록이 비었거나 위젯을 새로 띄웠다면 **프레임 새로고침**을 누릅니다.

## 3. 요소에서 모듈 찾기

### 방법 A: Elements 탭 (가장 간단)

Elements 탭에서 요소를 선택하면 사이드바에 결과가 나옵니다. 화면에서 우클릭 → **검사**로 선택해도 됩니다. iframe 안의 요소도 해당 프레임을 자동으로 찾아 조회합니다.

### 방법 B: 패널의 **요소 선택**

**요소 선택**을 누른 뒤 위젯 화면에서 요소를 클릭합니다. 그 클릭은 위젯에 전달되지 않습니다. 취소하려면 Esc를 누릅니다.

### 결과 읽는 법

```
[3di] span.title
↑1 div.chg-panel
  create             DS/.../Panel (Object.show) ← DS/.../Home (Object.render)
  innerHTML          DS/.../Panel (Object.show)
  listen:click       handler DS/.../Home
  nls FixtureNLS.PANEL.TITLE [template] "Panel {0}"
      DS/.../Home  ENOChgFixture.js:1:345
```

| 표시 | 의미 |
| --- | --- |
| 첫 줄 | 선택한 요소 |
| `↑N 요소` | 기록이 선택한 요소가 아니라 N단계 위 부모에 있음 |
| `create` | 요소를 만든 모듈. `←` 오른쪽은 그 코드를 호출한 모듈 |
| `insert` | 요소를 화면에 붙인 모듈 |
| `innerHTML` | HTML 문자열로 내용을 채운 모듈 |
| `listen:이벤트` | 이벤트를 등록한 모듈. `handler`는 실제 핸들러 함수가 있는 모듈 |
| `nls 이름.키 [종류] "문구"` | 화면 문구에 해당하는 NLS 키 |
| NLS 아래 줄 | 그 키를 쓰는 모듈과 `파일:줄:열` 위치. `(추정)`은 정확히 확인하지 못한 위치 |

NLS 일치 종류:
- `exact`: 문구가 완전히 같음
- `template`: `{0}` 같은 자리 표시자를 채운 형태
- `partial`: 일부만 일치

**"기록 없음"**이 나오면 페이지를 새로고침한 뒤 다시 시도하세요. 위젯 번들(`/webapps/ENOChg...`) 밖에서 만들어진 요소일 수도 있습니다.

## 4. 진단

패널의 **진단**을 누르면 맨 위에 요약이 나옵니다.

```
[정상] 대상 번들 3개
[정상] 요소 기록 1520건
[정상] 이벤트 버스 PlatformAPI 연결
[문제] 이벤트 버스 ModelEvents 미연결: 모듈이 아직 로드되지 않았거나 모듈 ID가 바뀜
[정상] NLS 2개 모듈
[정상] 오류 없음
```

`[문제]` 줄에는 원인과 조치가 함께 적혀 있습니다. 그 아래의 상세 줄은 개발할 때 참고하는 정보입니다.

## 5. NLS 검색 (화면 문구 → 키 → 모듈)

**화면 문구** 입력란에 화면에 보이는 글자를 넣고 **NLS 검색**(또는 Enter)을 누릅니다. 결과는 일치한 NLS 키와, 그 키를 쓰는 모듈 및 위치입니다. 공백과 대소문자는 구분하지 않습니다.

## 6. 이벤트 로그

위젯 내부 이벤트 버스(`PlatformAPI`, `ModelEvents`)의 publish 기록을 봅니다.

1. 화면에서 동작을 수행합니다(버튼 클릭 등).
2. **이벤트 필터**에 이벤트 이름 일부를 넣고(비우면 전체) **이벤트**를 누릅니다.

```
10:21:03.120 [PlatformAPI] FIX_OPEN {"id":1}
    pub ← DS/.../Home (onClick)
    sub → DS/.../Panel
```

| 표시 | 의미 |
| --- | --- |
| `pub ←` | 이벤트를 보낸 모듈 |
| `sub →` | 이벤트를 받는 모듈 |
| `미확인 N` | 받는 쪽 모듈을 찾지 못한 구독 수 |

최근 500건까지 보관합니다.

## 7. 모듈 보기 (변수명 복원)

**모듈 ID** 입력란에 `DS/...` 모듈 ID를 넣고 **모듈 보기(이름 복원)**를 누릅니다.

```
// e → UserPreferenceUtil = DS/ENOChgServices/scripts/services/UserPreferenceUtil
// o → ENOChgGovernanceNLS = i18n!DS/ENOChgGovernanceUX/assets/nls/ENOChgGovernanceNLS
define("...", [...], function (UserPreferenceUtil, ..., ENOChgGovernanceNLS) {
  ...
```

- 모듈 상단의 파라미터 이름(`e`, `t`, `o` …)을 의존 모듈 이름으로 바꾸고 들여쓰기를 정리해서 보여줍니다.
- 함수 안에서 같은 이름을 새로 선언한 부분은 다른 변수이므로 바꾸지 않습니다.
- **읽기 전용**입니다. 이 화면의 코드를 패치 앵커로 쓰면 안 됩니다. 앵커는 반드시 원본 번들에서 복사합니다.

## 8. 패치 (번들 수정 파일 만들기)

### 8-1. 패치 작성

패널 아래 입력란에 다음 형식으로 적습니다.

```
@@ DS/ENOChgGovernanceUX/scripts/view/changeRequest/ChgCreateChangeRequest
<<<<
o.CHG_NEW_CHANGE_REQUEST_FORM
====
o.CHG_NEW_CHANGE_REQUEST_FORM + "!"
>>>>
```

- `@@ 모듈ID` 아래에 `<<<<` 찾을 문자열 `====` 바꿀 문자열 `>>>>` 블록을 여러 개 둘 수 있습니다.
- `<<<<`, `====`, `>>>>`는 각각 한 줄에 단독으로 씁니다.
- **찾을 문자열은 원본 번들에서 복사**합니다. Sources 탭에서 번들을 열거나 Network 탭의 응답에서 복사하면 됩니다.
- 찾을 문자열은 해당 모듈 안에서 **딱 한 곳**에만 있어야 합니다. 여러 곳이면 앞뒤를 더 붙여 길게 지정합니다.
- 다른 모듈의 패치는 `@@` 줄을 새로 시작합니다. 서로 다른 번들 파일에 걸쳐도 됩니다.
- 입력한 내용은 패널을 다시 열어도 남아 있습니다.

### 8-2. 패치 검사

**패치 검사**를 누르면 패치마다 판정이 나옵니다.

| 판정 | 의미 / 조치 |
| --- | --- |
| 적용 가능 | 정상 |
| 이미 적용됨 | 현재 로드된 번들에 이미 반영됨(Local Overrides 적용 후 정상) |
| 앵커 없음 | 찾을 문자열이 없음. 버전이 바뀌었을 수 있으니 원본에서 다시 복사 |
| 앵커 N곳 일치 | 더 길게 지정 |
| 다른 패치와 겹침 | 두 패치의 찾을 범위가 겹침. 하나로 합치기 |
| 모듈 없음 | 모듈 ID 오타이거나, 선택한 프레임에 그 모듈이 없음 |

변경이 있으면 **구문 검사**(수정 후 코드가 문법적으로 올바른지)도 함께 표시됩니다.

### 8-3. 패치 파일 저장

**패치 파일 저장**을 누르면 수정된 번들이 원본과 같은 파일 이름(예: `ENOChgGovernanceUX.js`)으로 다운로드 폴더에 저장됩니다. 모든 판정이 "적용 가능" 또는 "이미 적용됨"이고 구문 검사가 정상일 때만 저장됩니다.

### 8-4. 화면에 반영 (Local Overrides)

서버를 바꾸지 않고, 내 크롬에서만 수정된 파일로 바꿔 실행하는 기능입니다.

**처음 한 번만 설정:**
1. 개발자도구 **Sources** 탭 → 왼쪽 **Overrides** → **Select folder for overrides**를 누르고 빈 폴더(예: `C:\overrides`)를 지정합니다.
2. 상단에 뜨는 접근 허용 요청에서 **허용**을 누릅니다.

**파일마다:**
1. **Network** 탭에서 원본 번들(예: `ENOChgGovernanceUX.js`)을 우클릭 → **Override content**를 누릅니다.
2. 오버라이드 폴더 안에 `호스트/경로/파일명` 구조로 같은 이름의 파일이 생깁니다. 그 파일을 저장한 패치 파일로 교체합니다.
3. 페이지를 새로고침합니다.
4. 패널에서 **패치 검사**를 다시 눌러 "이미 적용됨"으로 나오면 반영된 것입니다.

**주의:**
- Local Overrides는 **개발자도구가 열려 있을 때만** 동작합니다.
- 되돌리려면 Sources → Overrides에서 해당 파일을 삭제하거나, **Enable Local Overrides** 체크를 해제합니다.

## 9. 콘솔에서 쓰기

확장이 들어간 프레임에서는 콘솔에서도 같은 기능을 쓸 수 있습니다. 먼저 콘솔 상단의 컨텍스트 드롭다운에서 위젯 iframe을 고릅니다.

| 명령 | 기능 |
| --- | --- |
| `__3di.pick()` | 요소 클릭으로 조회 |
| `__3di.inspect($0)` | Elements에서 선택한 요소 조회 |
| `__3di.nls('화면 문구')` | NLS 검색 |
| `__3di.events('필터')` | 이벤트 로그 |
| `__3di.watch('필터')` / `__3di.watch(false)` | 이벤트 실시간 출력 켜기 / 끄기 |
| `__3di.diag()` | 진단 |
| `__3di.stop()` | 기록 중지 및 원상 복구 |

### 확장을 쓸 수 없을 때 (콘솔 스니펫)

`dist/3d-inspector.js`의 내용을 위젯 iframe 컨텍스트의 콘솔에 붙여 넣고 실행하면, 위 콘솔 명령을 똑같이 쓸 수 있습니다. 다만 붙여 넣은 **이후에 만들어진 요소만** 기록되므로, 실행한 뒤 화면을 다시 그리게(탭 이동, 목록 새로고침 등) 해야 합니다. 패치와 모듈 보기는 확장에서만 됩니다.

## 10. 한계

- `async`/`await`나 타이머를 거친 코드는 호출 스택이 끊겨서 `←` 이후 모듈이 일부 빠질 수 있습니다.
- `.bind()`로 감싼 핸들러나 구독 함수는 모듈을 찾지 못해 `미확인`으로 나올 수 있습니다.
- NLS 객체를 다른 변수에 옮겨 담아 쓰는 코드는 사용 위치가 `(추정)`으로 표시됩니다.
- 확장은 현재 모든 사이트에 주입됩니다(`manifest.json`의 `matches`가 `<all_urls>`). 3DEXPERIENCE 주소가 정해지면 그 주소로 좁힐 수 있습니다.
